# EduShield AI

**Protecting Education Funding Through Intelligence.**

AI-assisted fraud detection, identity protection and investigation for U.S. student financial aid offices.
EduShield AI is a *decision-support* system: it never denies aid or labels a student fraudulent on its own.

> Work in progress — the full README (architecture, demo script, capability status) is written in the final phase.

## Quick start

```bash
make install   # backend venv + frontend node_modules
make migrate   # apply database migrations
make seed      # load synthetic demonstration data
make dev       # API on :8000, web client on :5173
```
